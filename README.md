## 👨‍💻 About me

I'm a **Software Engineer** focused on designing and building complete, production-ready software platforms.

My work goes beyond implementing features. I enjoy thinking about the entire lifecycle of a system:

**architecture → APIs → data → asynchronous processing → frontend → mobile → infrastructure → observability → delivery**

I work primarily with **TypeScript and the Node.js ecosystem**, building distributed applications with **NestJS, React, Next.js and React Native**, backed by PostgreSQL, Redis, RabbitMQ and containerized infrastructure.

Currently, much of my engineering work is focused on **Tchr**, an education platform I'm building around multi-tenancy, marketplaces, payments, streaming, communities and learning experiences.

# ⚙️ How I think about software

```typescript
const engineering = {
  product: "Solve the right problem",
  architecture: "Design for change",
  code: "Keep it understandable",
  infrastructure: "Automate what repeats",
  observability: "If you can't see it, you can't operate it",
  performance: "Measure before optimizing",
  security: "Treat it as architecture, not a feature",
  scalability: "Earn complexity when you need it",
};
```

I believe good engineering isn't about using the largest number of technologies.

It's about making **good trade-offs** and building systems that teams can understand, operate and evolve.
